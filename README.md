# EduPath — Adaptive AI Career Learning

> **Learn. Assess. Adapt. Repeat.**

EduPath is an adaptive AI career-learning system that helps learners move from their current skill set toward a target career role.

Instead of generating a static learning roadmap, EduPath creates a personalized path from the learner's resume, identifies skill gaps, provides a focused 7-day learning plan, and uses assessment feedback to recalibrate the next learning step.

---

## The Problem

Most learning platforms provide a predefined roadmap:

**Choose a career → Follow a roadmap → Learn**

But learners do not progress in exactly the same way.

A learner may understand one topic quickly and struggle with another. A static roadmap does not respond to that difference.

EduPath explores a different approach:

**Understand → Identify → Learn → Assess → Adapt**

The goal is to make the learning path responsive to evidence about the learner rather than treating the roadmap as fixed.

---

## What EduPath Does
